# Blender — Phase 2 3D control room

Procedural blockout for the walkable plant phase (plan U6→Phase 2 bridge).
The scene is generated by Python so it stays regenerable and diffable.

## Regenerate

```
"C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" -b --python Blender/scripts/make_control_room.py
```

Writes `Blender/ControlRoom.blend`.

## Export to Unity

Open `ControlRoom.blend` in Blender, run `Blender/scripts/export_unity.py`
(or headless: `blender -b --python Blender/scripts/export_unity.py`),
then drop `exports/ControlRoom.fbx` into `ReactorSim.Unity/Assets/Models/`.

## Collections

- `Room` — floor, walls
- `MimicWall` — gauges (`Mimic_Gauge_*`), rod banks (`Mimic_RodBank_*`),
  status board, assistant terminal, SCRAM (`SCRAMPushButton`)
- `OperatorStations` — Station A1 (reactor) / A2 (balance of plant), 3 screens each
- `Plant` — containment glass, reactor pressure vessel, pressurizer,
  steam generators, coolant pumps, primary loop piping

Named objects are the future Unity binding points for `PlantBridge`.

## Trim-sheet bake

```
"C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" -b --python-exit-code 1 --python Blender/scripts/bake_trim_sheets.py [-- --res 1024]
powershell -ExecutionPolicy Bypass -File Blender/scripts/sync-blender-to-unity.ps1
```

Bakes the 8 master materials to `exports/Textures/`:
`T_<mat>_BaseColor` (sRGB albedo), `T_<mat>_MetallicSmoothness` (R metallic,
A smoothness; imported linear), `T_<mat>_Emission` (emissive masters only), plus
`AnnunciatorAtlas_24.png`. The sync copies them to
`ReactorSim.Unity/Assets/Blender/Textures/`, where `BlenderAssetPostprocessor`
binds them onto the FBX materials of the same name and re-imports the FBX when a
map changes. The .blend files are opened read-only and never re-saved.
